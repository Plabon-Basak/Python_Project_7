# Python OOP Projects Collection

A collection of four Python projects demonstrating core Object-Oriented Programming (OOP) concepts including inheritance, polymorphism, encapsulation, and abstraction.

## Projects

### 1. Animal Sound Simulator
Demonstrates **inheritance** and **polymorphism** through a base `Animal` class and derived classes (Dog, Cat, Cow, Duck), each overriding the `make_sound()` method.

### 2. Secure User Profile App
Showcases **encapsulation** with a `UserProfile` class that uses private/protected attributes for email and password, with getter/setter methods and input validation.

### 3. Inventory Management System
Illustrates **instance methods**, **static methods**, and **class methods** for managing products, calculating discounts, and tracking total inventory.

### 4. Mini ATM Machine
Combines **encapsulation**, **static/class methods**, and **polymorphism** to simulate an ATM system with secure PIN authentication and account operations.
